### 👨‍💻 About Me

Grounded in **Front-End Architecture & Clean Code principles**, I am actively combining engineering discipline with **Financial Data Analysis**. My mission is to harness the analytical capabilities of Python and modern data pipelines to process, analyze, and visualize **Indonesia Stock Exchange (IDX)** capital market data for data-backed decision making.
